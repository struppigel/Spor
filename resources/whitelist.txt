# Spor whitelist: known-noise rules. Hidden items are counted ("Hidden: ..."), -nowhitelist lists them.
# This file says WHERE noise is; the code says WHEN it may be hidden (validly signed, no strong flags, 0 bytes, system
# drive only, ...), so a rule here never hides a file with a bad signature or a strong flag.
# Columns (tab-separated): scope, value, note (optional). Lines starting with # are comments.
# Spor.whitelist.txt next to Spor.exe replaces this file (to try a rule without a new build); one that cannot be read
# or has an error (unknown scope, bad regex) is ignored and the built-in file is used.
#
# Scopes (regex = .NET regex, case-insensitive, against the path WITHOUT its drive: \USERS\X\APPDATA\...;
# the lines of one scope are joined with |):
#   noise:prefetch   regex  loaded files PREFETCH does not list (known noise)
#   noise:amcache    regex  AMCACHE entries counted as known noise
#   noise:exec       regex  EXECUTION EVIDENCE entries counted as known noise
#   noise:files      regex  NEW FILES: validly signed files without flags counted as known noise
#   staging          regex  updater staging folders (in Program Files / Windows on the system drive only): NETWORK, AMCACHE
#   script-noise     regex  NEW FILES: folders where scripts are normal (not listed as new scripts)
#   breadcrumb       regex  NEW FILES: folders of empty marker files (0 bytes only)
#   skip-dir         name   NEW FILES: folder names not searched (caches, package folders)
#   stale-task       task => program   PERSISTENCE: Windows tasks whose System32 program feature updates remove
#   locked-task      task   PERSISTENCE: Windows tasks only SYSTEM can read (access denied is counted, not an error)
# Aggressive whitelist (command line -aggressive only; without it the lines are marked, see docs/.WHITELISTING.md):
#   aggr:pair        regex => signer   per-user apps: a program in this folder, validly signed by exactly this signer
#   aggr:staging     regex  more updater staging folders (system drive only): NETWORK
